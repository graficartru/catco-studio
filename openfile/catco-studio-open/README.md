# CatCo Studio — автономная версия сайта

Просто **дважды кликните по `index.html`** — сайт откроется в браузере.
Никаких серверов, установок и интернета не требуется: все скрипты, шрифты и
изображения лежат внутри папки.

## Структура
- `index.html` — главная страница (все данные студии вшиты прямо в страницу)
- `css/style.css` — стили
- `js/main.js` — логика сайта (слайдеры, фильтры портфолио, модальные окна, форма)
- `js/three.min.js` — локальная копия three.js (3D-сцена в первом экране)
- `data.json` — копия данных для редактирования (услуги, проекты, отзывы, форматы)
- `assets/img/gen/` — все изображения (рендеры, векторы, аватары)
- `publii-snippets/`, `publii-import.md` — фрагменты и инструкция для переноса в Publii

## Как редактировать контент
Основной источник данных — блок `<script id="catco-data" type="application/json">`
внутри `index.html` (строки ~260+). Правьте текст/картинки там; файл `data.json`
— его зеркало для удобства (после правки скопируйте JSON обратно в index.html).
Пути к картинкам указывайте относительно папки сайта, например
`assets/img/gen/hero_1.jpg`. Новые картинки кладите в `assets/img/gen/`.

## Форма заявки
Серверная отправка не подключена (это standalone-версия без backend). При
отправке форма честно сообщает об этом и сохраняет черновик в браузере.
Для реальной отправки включите Forms в Publii или пропишите endpoint сервиса
форм в блоке `"form"` данных страницы.

## Примечание про file://
Некоторые браузеры блокируют чтение соседних файлов при открытии со страницы
(`fetch`/XHR на `file://`). Поэтому все данные и библиотеки вшиты/загружаются
как обычные теги страницы — сайт работает полностью. Если решите публиковать
сайт на хостинге — используйте версию из архива `catco-studio-publii.zip`
(там абсолютные пути `/...`).
